# Auto Parking Trajectory Simulator

自动泊车轨迹规划仿真是一个浏览器版前端可视化项目，用于展示从车辆起点姿态到目标车位姿态的平滑泊车路径生成过程。

## 项目亮点

- 使用五次多项式平滑插值生成泊车轨迹，使起终点过渡更自然。
- 支持调节起点、终点、航向角和车位宽度。
- 在 Canvas 中展示道路、停车位、规划轨迹和车辆姿态。
- 实时计算轨迹长度、最大曲率、航向变化和车位余量。
- 单文件浏览器运行，不需要安装依赖。

## 快速运行

直接打开本目录下的 `index.html` 即可体验。

## 技术栈

- HTML
- CSS
- Vanilla JavaScript
- Canvas 2D
- 五次多项式平滑插值
- 轨迹几何指标计算

## 面向岗位的能力证明

这个项目重点证明三类能力：

- 智能车辆理解：能把自动泊车场景拆成起终点姿态、车位约束和轨迹指标。
- 算法表达能力：能用前端方式解释五次多项式轨迹生成思路。
- 工程展示能力：能把抽象路径规划过程转化成招聘方可点击、可观察的作品。

## 与旧项目的关系

仓库中的 `01/` 目录保留了 Streamlit 版本的智能汽车线控底盘与泊车仿真。本目录提供更适合作品集快速预览的浏览器版入口。

## 注意事项

- 当前版本用于轨迹规划概念展示，不包含障碍物预测、车辆动力学约束和控制器闭环跟踪。
- 如果用于面试讲解，建议说明后续可扩展到 Reeds-Shepp 曲线、MPC 跟踪或仿真平台联调。
