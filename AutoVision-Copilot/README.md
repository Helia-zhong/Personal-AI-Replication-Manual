# AutoVision Copilot

AutoVision Copilot 是一个浏览器版行车场景理解助手 Demo，用于展示多模态视觉语言模型在驾驶画面分析、风险判断和驾驶建议中的产品交互形态。

## 功能

- 场景模式选择：支持城市道路、高速公路和停车场三类场景。
- 图片 / 视频上传：支持上传行车图片或视频，视频会截取首帧作为预览。
- 预设问题：根据当前场景提供快速提问入口。
- 对话式分析：通过聊天界面展示目标检测、风险等级和驾驶建议。
- 视觉结果展示：在上传画面下方展示模拟标注和风险提示。
- 单文件运行：无需构建、无需安装依赖，直接在浏览器打开即可。

## 快速开始

1. 下载或克隆仓库。
2. 打开本目录下的 `index.html`。
3. 选择场景模式。
4. 上传一张行车图片或视频。
5. 选择预设问题或手动输入问题，查看模拟分析结果。

## 注意事项

- 当前版本为 Mock 演示，不会真正调用视觉模型或云端 API。
- 上传的图片和视频只在本地浏览器中处理，不会上传到服务器。
- 风险等级、检测对象和驾驶建议来自预设响应，适合作为产品原型展示，不可作为真实驾驶决策依据。
