# Vehicle Manual Knowledge Base

## 胎压报警

当仪表显示胎压报警时，应先降低车速并避免急转向或急制动。将车辆停放在安全位置后检查四个轮胎是否漏气、鼓包或被异物扎入。若轮胎外观正常，可使用胎压表测量胎压，并按照驾驶员侧门框标签建议值补气。补气后需要在中控系统中执行胎压复位或重新学习。

## 低压蓄电池报警

低压蓄电池报警通常表示 12V 电池电压偏低或充电系统异常。若车辆仍可启动，应关闭非必要用电设备，并尽快检查电池接线、发电机或 DC-DC 转换器状态。若车辆无法启动，不建议反复点火，应联系道路救援。

## 自适应巡航

自适应巡航用于在高速或快速路场景下维持设定速度和跟车距离。驾驶员需要保持对方向盘和路况的监控。雨雪、急弯、拥堵加塞或前方静止目标可能影响系统判断，此时应主动接管。

## 车道保持

车道保持辅助依赖摄像头识别道路标线。当车道线模糊、强光照射、雨雪天气或施工改道时，系统可能退出或误判。该功能不能替代驾驶员控制方向，双手应保持在方向盘上。

## 自动泊车

自动泊车功能会搜索可用车位并规划入库路径。使用时应低速行驶，确认车位周围没有行人、低矮障碍物和移动目标。系统执行泊车时，驾驶员仍需观察周围环境，并准备随时制动。

## 充电注意事项

连接充电枪前应确认接口干燥、无异物、无明显破损。充电过程中若闻到异味、看到烟雾或听到异常声音，应立即停止充电并远离车辆。雨天充电应使用符合标准的充电设备。

## 冷却液温度过高

如果仪表提示冷却液温度过高，应尽快减速并选择安全位置停车。不要立即打开高温状态下的冷却液壶盖，以免烫伤。等待温度下降后检查冷却液液位，并联系维修人员排查风扇、水泵或管路问题。

## 制动系统报警

制动系统报警可能与制动液液位、制动助力、ABS 或电子稳定系统有关。若制动踏板变硬、制动距离变长或车辆跑偏，应停止继续行驶并联系维修。若只是短暂提示，也应尽快进行诊断。
