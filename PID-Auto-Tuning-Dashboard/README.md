# PID Auto Tuning Dashboard

线控转向 PID 智能调参大屏是一个浏览器版控制系统原型，用于展示手动 PID 参数与智能寻优参数在阶跃响应中的差异。

## 项目亮点

- 面向车辆线控转向场景，围绕目标转角、超调量、调节时间和稳态误差组织界面。
- 提供 Kp、Ki、Kd 参数滑块，支持即时观察手动调参效果。
- 内置粒子群搜索思路，模拟智能寻优过程并展示适应度收敛曲线。
- 使用 Canvas 绘制目标曲线、手动 PID 响应和 AI 优化响应。
- 单文件浏览器运行，不需要安装依赖。

## 快速运行

直接打开本目录下的 `index.html` 即可体验。

## 技术栈

- HTML
- CSS
- Vanilla JavaScript
- Canvas 2D
- PID 参数响应近似仿真
- PSO 参数搜索思路

## 面向岗位的能力证明

这个项目重点证明三类能力：

- 车辆控制理解：知道 PID 参数、阶跃响应和控制性能指标之间的关系。
- AI 工程化表达：能把算法寻优过程包装成可交互、可解释的工具。
- 数据可视化：能把响应曲线、收敛曲线和关键指标做成招聘方容易扫读的演示界面。

## 与旧项目的关系

仓库中的 `02/` 目录保留了 Streamlit 版本的 PID 自动调参系统。本目录提供更适合作品集快速预览的浏览器版入口。
