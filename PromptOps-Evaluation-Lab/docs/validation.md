# PromptOps 验证记录

## 已验证

- Python 评分引擎、模拟评估、Ollama 请求构造、Token 校验和单个用例失败保留。
- CLI `--compare` 仍输出三组 Prompt 的完整用例结果，并支持 `--output` 保存 JSON。
- FastAPI 默认模拟接口保持兼容；`provider=ollama&model=...` 可切换到本机模型。
- 浏览器页面继续使用本地模拟器，GitHub Pages 不发送 Prompt 内容。

## 评分边界

当前数据集有 5 个固定用例，评分由关键字覆盖、格式遵循、禁止词命中和安全拒答组成。它适合作为 Prompt 版本回归门禁，不是独立盲测集，也不代表真实模型的通用准确率。

真实模型运行时，每个用例都保存模型名、延迟、输入 / 输出 Token、原始响应和错误信息。连接失败、超时、HTTP 错误或无效响应会进入对应结果，不会回退到模拟答案。
