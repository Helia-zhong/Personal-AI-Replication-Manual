# 启动说明

## 命令行启动

在本目录打开命令提示符（CMD）或 PowerShell，执行：

```bash
python -m pip install -r requirements.txt
python -m streamlit run app3.py
```

## 指定端口启动
如果默认端口被占用，可以指定其他端口：

```bash
python -m streamlit run app3.py --server.port 8502
```

## 启动后
- 浏览器会自动打开 http://localhost:8501
- 如果没有自动打开，请手动在浏览器中访问该地址
- 使用左侧滑块调节参数，实时查看仿真结果

## 常见问题

### 端口被占用
错误信息：`Address already in use`

解决方法：
```bash
python -m streamlit run app3.py --server.port 8502
```

### 浏览器没有自动打开
手动打开浏览器，访问：http://localhost:8501

### 依赖缺失
运行以下命令重新安装：
```bash
python -m pip install -r requirements.txt
```

## 停止服务
在命令行窗口按 `Ctrl + C`
